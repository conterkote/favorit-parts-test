# PARTLINE

Тестовое задание: приложение для поиска автозапчастей по артикулу с использованием API Favorit Parts.

**Демо:**

## Возможности

- Поиск производителей по артикулу и получение предложений выбранного бренда.
- Отдельные секции искомой детали и аналогов с ценой, остатком и датой отправки.
- Сравнение предложений разных складов, фильтр наличия и сортировка по цене или дате отправки.
- Постепенное отображение аналогов при прокрутке.
- Адаптивный интерфейс с пошаговым подбором на телефоне.
- Обработка загрузки, пустых результатов и ошибок с повтором запроса. Отмена предыдущих запросов и защита от устаревших ответов.

Для проверки можно использовать артикулы `01089`, `7160500039S` или `0189`.

## Стек

React, JavaScript, Redux Toolkit, Vite, CSS, Lucide. Структура компонентов организована по слоям FSD с публичными экспортами через `index.js`.

Запросы к Favorit Parts проходят через серверный прокси на Node.js. По умолчанию используется публичный тестовый ключ из документации API; данные приходят из внешнего сервиса.

## Запуск

Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Приложение доступно по адресу [http://127.0.0.1:5173](http://127.0.0.1:5173).
